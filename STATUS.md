# locksmitch-app - статус (2026-11-20)

Приложение на телефон для LocksMitch: app.locksmitch.com. Статика на GitHub Pages (репозиторий dmytro-s88/locksmitch-app), данные из бота (`LocksMitch-bot/src/App.gs`). Спек и план в `LocksMitch-bot/docs/superpowers/`.

## Состояние
- Версия: v0.23 (Hand off без суммы не закрывает лид: он уходит из Open и ждёт в Money в карточке «With colleagues» с кнопками He did it / Got paid / Back to me / Lost / Nothing owed; бот v283; v0.22: hand-off: в лиде кнопка «🤝 Hand off» — кто взял работу и, если известно, сумма; лид закрывается как работа коллеги и уходит из открытых и из «Not paid yet»; в Money у неоплаченного лида «Colleague did it»; бот v282; v0.21: доход по лиду: в Money кнопка «+ Income» (выбор работы: сделанные без оплаты и открытые лиды) и карточка «Not paid yet» с кнопкой Add payment; в сделанном лиде без суммы кнопка «$ Add payment»; «No charge» убирает бесплатную работу из списка; бот v281; v0.20: в предпросмотре SMS-спасибо кнопка «Without warranty» / «With warranty», бот v276; v0.19: в Jobs у ключа видна мелочь: «+ chip $1.69 + blade $0.80», бот v274; v0.18: в лиде карточка «Codes»: VIN и PIN с копированием по тапу, бот v273; v0.17: в лиде кнопка «📦 Waiting for keys» = статус «Ждём ключи», бот v272; работа без оплаты с расходами видна в Jobs минусом; v0.16: в Money у работы строка «🧾 AutoCode $42» — прочие расходы работы (PIN-коды), вычтены из «осталось», в итоге «Other», бот v271; v0.15: в карточке лида кнопка «🤔 Thinking» = статус «Клиент думает», бот v269; v0.14: в Money карточка «Jobs · key cost»: по каждой работе ключ и цена, угадывает бот v268, тап по работе = выбор из стока; v0.13: вкладка в Money называется Day вместо Today; v0.12: чеки: карточка «Checks not cashed» с кнопкой Cashed в Money, метка «check not cashed» в операциях; бот v267; v0.11: в Money вкладки Today / Month: «Earned» за день крупно, стрелки по дням, операции дня; бот v266; v0.10: оплата «Check» в Done и в «Mark paid» чека; v0.9: кнопка Go открывает Google Maps (на iPhone приложение через comgooglemaps://, иначе ссылка google.com/maps), тап по адресу копирует его; v0.8: второй тап по Today открывает дни недели: Today, Yesterday, Fri 11/13 … — лиды созданные, сделанные или с визитом в этот день; v0.7: у назначенных в плашке дата и время визита, в карточке «Visit: …»; v0.6: видимая загрузка: полоска, спиннеры на кнопках и строках; v0.5: все четыре экрана из спека готовы; после ревью: экран не перерисовывается при смене сети, набранные строки чека и форма расхода не теряются; «Назад» подгружает список; кнопки оплаты блокируются на время запроса; при неудачной SMS текст остаётся на экране с кнопкой «Open Messages»; service worker отдаёт index.html из сети, свежий деплой доходит при следующем открытии. v0.4: экран денег: месяц ‹ ›, плитки доход / расходы / прибыль / мили, долги коллег, последние операции, «+ Expense»; экран чека: строки из лида, правка, Create invoice / estimate, PDF, Sign, Print, Paid cash / Zelle / card; вход по коду из /app, список Open/Today/Done, карточка: адрес, мили, Call/Text/Go, подсказка цены, чеки, заметки; действия Done / Call back / Scheduled / Lost / Price / Note / Confirm text / Thank-you text с предпросмотром SMS и откатом при ошибке). 
- Деплой: `git push` в main → GitHub Pages. После правок css/js поднять `?v=` в index.html и `CACHE` в sw.js.
- Тесты: `node --test core.test.js`.
