# locksmitch-app - статус (2026-11-20)

Приложение на телефон для LocksMitch: app.locksmitch.com. Статика на GitHub Pages (репозиторий dmytro-s88/locksmitch-app), данные из бота (`LocksMitch-bot/src/App.gs`). Спек и план в `LocksMitch-bot/docs/superpowers/`.

## Состояние
- Версия: v0.31 (плашка работы коллеги: «Done · hand off» / «Handed off»; v0.30: Done с суммой 0 = бесплатная работа, плашка «Done · free»; бот v305; v0.29: после Done в карточке лида сразу окно «which key did you use?» со списанием из стока, ссылка `?key=N` из Telegram открывает лид и это окно; бот v299; v0.28 в Money третья вкладка Week: неделя пн–вс со стрелками, «Earned this week», плитки, Jobs · costs и операции за неделю; бот v294; v0.27: в Money под плиткой Miles примерное списание за мили по ставке IRS)
- Деплой: `git push` в main → GitHub Pages. После правок css/js поднять `?v=` в index.html и `CACHE` в sw.js.
- Тесты: `node --test core.test.js`.
