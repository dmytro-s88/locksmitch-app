# locksmitch-app - статус (2026-11-16)

Приложение на телефон для LocksMitch: app.locksmitch.com. Статика на GitHub Pages (репозиторий dmytro-s88/locksmitch-app), данные из бота (`LocksMitch-bot/src/App.gs`). Спек и план в `LocksMitch-bot/docs/superpowers/`.

## Состояние
- Версия: v0.9 (кнопка Go открывает Google Maps (на iPhone приложение через comgooglemaps://, иначе ссылка google.com/maps), тап по адресу копирует его; v0.8: второй тап по Today открывает дни недели: Today, Yesterday, Fri 11/13 … — лиды созданные, сделанные или с визитом в этот день; v0.7: у назначенных в плашке дата и время визита, в карточке «Visit: …»; v0.6: видимая загрузка: полоска, спиннеры на кнопках и строках; v0.5: все четыре экрана из спека готовы; после ревью: экран не перерисовывается при смене сети, набранные строки чека и форма расхода не теряются; «Назад» подгружает список; кнопки оплаты блокируются на время запроса; при неудачной SMS текст остаётся на экране с кнопкой «Open Messages»; service worker отдаёт index.html из сети, свежий деплой доходит при следующем открытии. v0.4: экран денег: месяц ‹ ›, плитки доход / расходы / прибыль / мили, долги коллег, последние операции, «+ Expense»; экран чека: строки из лида, правка, Create invoice / estimate, PDF, Sign, Print, Paid cash / Zelle / card; вход по коду из /app, список Open/Today/Done, карточка: адрес, мили, Call/Text/Go, подсказка цены, чеки, заметки; действия Done / Call back / Scheduled / Lost / Price / Note / Confirm text / Thank-you text с предпросмотром SMS и откатом при ошибке). 
- Деплой: `git push` в main → GitHub Pages. После правок css/js поднять `?v=` в index.html и `CACHE` в sw.js.
- Тесты: `node --test core.test.js`.
